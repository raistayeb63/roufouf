# رَفوف — مكتبة المعهد

موقع ثابت بواجهة عربية، مع فهرس مشترك وطلبات استعارة محفوظة في Supabase.

## النشر

يستخدم المستودع GitHub Actions لنشر محتوياته إلى GitHub Pages عند تحديث فرع `main`. بعد رفع الملفات، فعّل Pages من إعدادات المستودع واختر GitHub Actions كمصدر النشر.

## Supabase

- المشروع: `rafouf-library` (منطقة `eu-west-1`).
- الإعداد العام للمتصفح موجود في `supabase-config.js`، ويحتوي رابط المشروع ومفتاح publishable فقط.
- لا تضع مفتاح secret أو service-role في ملفات الموقع.
- أنشئ حساب مسؤول المعهد من صفحة بوابة المعهد باستخدام البريد المعتمد، ثم أكّد رسالة البريد وسجّل الدخول.
- بوابة المعهد تجلب الطلبات كل ست ثوانٍ، ويُطبّق الخادم صلاحيات المسؤول ويمنع حجز النسخة نفسها مرتين.

لا ترفع كلمات مرور أو مفاتيح سرية إلى المستودع.
